# CHRISTMAS BINGO! 2026

「47都道府県 BINGO!」を参考に、新規・独立して作成したクリスマス用ビンゴWebアプリです。既存リポジトリには変更しません。

## 使い方

1. GitHub PagesのURLをPCまたはiPadのブラウザで開きます。
2. 「イラストを読み込む」を押し、手元の `クリスマス.zip` を選びます。ZIPを解凍する必要はありません。
3. イラストとタイトルのルーレットを「スタート」で抽選します。抽選済みのイラストは重複しません。
4. 右側の履歴を「タイトル／イラスト」「固定順／抽選順」で切り替えられます。初期表示は **タイトル＋固定順** です。
5. 「カード作成」タブでは枚数指定で一括生成し、「1枚追加」で必要に応じて追加できます。
6. カードは4×4、20種類から16種類の重複なし抽出、1枚ずつプレビュー可能。名前記入欄、No.001からの連番が付きます。
7. 「PDFを出力」で **A4横向き・2枚／ページ・中央切り取り線・印刷余白あり** のPDFをダウンロードします。

## 画像の扱い

イラストのZIPはブラウザ上だけで展開します。画像がサーバーへアップロードされることはなく、GitHubにも同梱しません。ファイル名（拡張子を除く）をそのままタイトルとして利用します。同名のPNGは重複不可。16枚以上で動作します。

抽選・生成カード・ZIPの読み込み状態は**保存しません**。ページを再読み込みすると初期化されます。ルーレットのリセットボタンは抽選履歴だけを初期化し、生成カードは維持します。

## 公開方法

新規リポジトリ `ssy224fos-beep/christmas-bingo-2026` を作成し、`index.html`、`style.css`、`script.js`、`vendor/` をアップロードしてください。

GitHub上で Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save と設定します。

公開URLは、Pagesが有効になり反映されたら通常 `https://ssy224fos-beep.github.io/christmas-bingo-2026/` になります。
